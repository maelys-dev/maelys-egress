# Releasing maelys-egress

Releases go through the shared maelys-release socle (v0.2.0). The
workflow `.github/workflows/release.yml` is generated by its `adopt.sh`.

1. On `main`: `VERSION` = `X.Y.Z`, dated `CHANGELOG.md` entry, generated
   documentation regenerated, `make check` green on the exact commit.
2. Merge through a pull request with green CI.
3. `git tag -s vX.Y.Z -m "maelys-egress X.Y.Z" && git push origin vX.Y.Z`.
4. The workflow verifies the signed annotated tag, builds the packages on
   Linux x86_64, Linux arm64 and macOS arm64, attests their provenance,
   publishes the GitHub release, then renders and publishes the Homebrew
   formula with its bottles.
5. Verify: `gh release view vX.Y.Z`, `gh attestation verify ASSET --repo
   OWNER/REPO`, `brew install maelys-dev/tap/maelys-egress`.

Upgrade the socle with `adopt.sh DIR --apply` from a maelys-release checkout
at the wanted tag; `adopt.sh DIR --check` reports drift with exit 2.
